# OfflineTodos app

This project shows how to use a local datastore through an Android Todos application.

## Android Quick Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/AlakhiarovSalekh/OfflineTodos-App.git
   cd OfflineTodos-App
   ```

2. Open the sample project in `android/` and the Parse UI project in `ParseUI-Android/` in your Android IDE.
3. The login UI module is located at `ParseUI-Android/ParseLoginUI/`.
4. Open `TodoListApplication.java` and configure it with your Parse application ID and client key.
5. Build and run the Android app.
