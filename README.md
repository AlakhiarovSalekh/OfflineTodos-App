# Offline Android Todo App — Local Datastore & Parse UI

[![Android](https://img.shields.io/badge/Android-Offline%20Todos-3DDC84?logo=android&logoColor=white)](https://developer.android.com/)
[![Stars](https://img.shields.io/github/stars/AlakhiarovSalekh/OfflineTodos-App?style=social)](https://github.com/AlakhiarovSalekh/OfflineTodos-App/stargazers)

An Android todo application demonstrating local/offline datastore usage together with a Parse-based Android UI module.

## Repository Structure

```text
android/          Todo application
ParseUI-Android/  Parse UI project used by the sample
```

## What It Demonstrates

- Android application structure
- Todo-list workflows
- Local/offline data handling
- Parse UI integration
- App configuration through the Android project

## Android Quick Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/AlakhiarovSalekh/OfflineTodos-App.git
   cd OfflineTodos-App
   ```
2. Open the sample project in `android/` and the Parse UI project in `ParseUI-Android/`.
3. The login UI module is under `ParseUI-Android/ParseLoginUI/`.
4. Review `TodoListApplication.java` and configure your own Parse application credentials where required.
5. Build and run the Android app.

> This is a legacy Android/Parse sample. Modern Android Studio versions or dependency changes may require compatibility updates.
